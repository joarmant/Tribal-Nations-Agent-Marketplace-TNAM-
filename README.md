# Tribal-Nations-Agent-Marketplace-TNAM-

## About

This repository is a place for Tribal Nations to share AI solutions built with
Microsoft technologies, in partnership with Microsoft. It aims to help Tribal
Nations learn from one another and develop solutions that address their
priorities and support tribal businesses and services.

## Areas of opportunity

Solutions shared here may support areas such as:

- **Tribal services:** agents that help people discover and access services.
- **Healthcare:** tools that support care delivery and community health.
- **Education:** solutions for learners, educators, and tribal education programs.
- **Gaming and casino operations:** agents and automations for hiring,
  procurement, vendor management, and other business functions.
- **Other tribal services and businesses:** solutions shaped by each Nation's
  needs and priorities.

These are examples, not limits on what Tribal Nations can contribute.

## Sharing a solution

When contributing a solution, include a README that explains the problem it
addresses, who it is for, how to set it up and use it, and any requirements or
limitations. Clearly identify what is needed to run it, including relevant
Microsoft services, and provide a way to test or evaluate it when practical.

Contributors should follow the data governance, privacy, security, and review
requirements set by the Tribal Nation responsible for the solution. Do not
include confidential, personal, or community-sensitive data, credentials, or
other secrets in this repository.
